# 数创方舟 · 未来农业的智慧方舟（3D 滚动叙事与移动端交互展示）

本项目为「数创方舟」一体化智能种植解决方案的 WebGL (Three.js) + GSAP ScrollTrigger 滚动驱动 3D 品牌叙事页。

## 在线体验与核心特性

[打开 GitHub Pages 网页](https://kindlysame55-tech.github.io/shuchuang-fangzhou/)

- **原有 3D 模型**使用 `models/shuchuang_fangzhou_mascot_opt.glb`（814 KiB，保留全部 14 个独立部件节点）。桌面端和手机端加载同一个模型。
- **自动适配**沿用原版响应式布局，根据浏览器窗口宽度切换布局和镜头。浏览器无法启动 WebGL 时，页面显示原有静态预览。
- **滚动驱动 6 章节叙事**：序章亮相 → 13 组立体胸徽浮雕拆解 → 夜间温室 AIoT 背面控制仓与实时遥测 → 农林实训基地四面彩绘展陈与四维价值 → 四大应用航道与三引擎商业生态 → 360° 自由巡检与扫码溯源。
- **触摸 / 滑动 3D 实体化漂浮交互**：支持手势拖拽惯性旋转、轻触弹簧悬浮跃动与卡片 3D 透视悬浮光感。

## 本地预览
```bash
node server.mjs
```
浏览器访问 `http://127.0.0.1:5178`（或手机访问终端输出的局域网地址）。
