# 数创方舟 · 未来农业的智慧方舟（3D 滚动叙事与移动端交互展示）

「数创方舟」一体化智能种植解决方案的 Three.js 品牌展示页。

## 在线体验

[打开 GitHub Pages 网页](https://kindlysame55-tech.github.io/shuchuang-fangzhou/)

- 桌面端随着滚动切换镜头。手机和平板可通过章节菜单跳转，在各章节展示区内拖动模型和查看交互。
- 手机和平板使用约 327 KB 的轻量模型，保留全部 14 个模型节点。桌面端使用原有的约 834 KB 模型。
- 页面先显示 WebP 预览，再加载 3D。省流量、慢速网络和减少动态效果模式下，可手动启动 3D。模型加载失败时仍可浏览正文、作物预设和四面彩绘。

GitHub Pages 从 `main` 分支的仓库根目录发布，无需构建。

## 本地预览
```bash
node server.mjs
```
浏览器访问 `http://127.0.0.1:5178`（或手机访问终端输出的局域网地址）。
